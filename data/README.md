# Data Directory

Large local datasets and embedding caches are intentionally not tracked. Put processed arrays and raw-count files under `data/` using the paths expected by the benchmark scripts.

Expected processed layouts include:

- `data/nCoV/`: `X1.npy`, `X2.npy`, labels, metadata, and optional raw-count `.h5ad` files.
- `data/human_brain/`: Boris sc processed arrays and metadata.
- `data/atac/`: ATAC processed arrays, `cells_metadata.csv`, and selected feature files.
- `data/lupus/`: lupus processed arrays, metadata, and optional `raw_counts.h5ad` for scVI.
- `data/mnist/`: synthetic two-batch MNIST arrays generated by `notebooks/mnist.ipynb`.
- `data/benchmark_embeddings/`: local aggregate `.npz` benchmark caches.

Use repository-relative paths in notebooks and scripts. Avoid committing raw data, `.h5ad` files, large aggregate caches, generated figures, or Slurm logs.
